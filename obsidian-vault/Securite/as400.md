# AS400 — Connexion ERP ↔ Site

## Contexte

L'AS400 (IBM iSeries) est l'ERP historique Reboul. La connexion AS400 ↔ reboulstore.com permettra de synchroniser stock, commandes et prix sans import CSV manuel.

## Questions pour l'expert — 12/05/2026

### Architecture réseau
- Quelle méthode de connexion : **VPN site-à-site**, IP whitelist, ou autre ?
- L'AS400 est-il exposé sur internet ou uniquement en réseau local Reboul ?
- Faut-il un **middleware** entre AS400 et NestJS, ou connexion directe ?
- Quel protocole : REST/HTTP, SOAP, fichiers SFTP batch, ou bus message ?

### Authentification & Secrets
- Comment authentifier les appels AS400 → site (API key ? certificat ?)
- Comment authentifier les appels site → AS400 (credentials IBM i, API dédiée ?)
- Gestion rotation des secrets de connexion — qui renouvelle, quelle fréquence ?

### Données en transit
- TLS obligatoire sur tous les flux ?
- Données sensibles dans les échanges (clients, adresses) → comment les protéger ?
- RGPD : les données clients peuvent-elles sortir vers l'AS400 ?

### Résilience & Fallback
- Que se passe-t-il si l'AS400 est indisponible ? Le site doit continuer à fonctionner
- Stratégie retry / file d'attente (Redis) pour les commandes non transmises
- Réconciliation en cas de désync stock AS400 ↔ site

### Audit & Monitoring
- Logs de tous les appels inter-systèmes (qui, quoi, quand, résultat)
- Alertes si la sync stock ne tourne plus
- Qui a accès aux logs AS400 côté Reboul ?

### Périmètre
- Quel module AS400 gère le stock ? Le catalogue ? Les commandes ?
- Y a-t-il une API existante sur l'AS400, ou faut-il en créer une ?
- Qui maintient l'AS400 chez Reboul (prestataire IBM i interne ?) ?

## Risques à anticiper

| Risque | Mitigation |
|--------|-----------|
| AS400 exposé sur internet sans auth forte | VPN ou IP whitelist strict |
| Données AS400 non validées → injection | Validation DTO NestJS sur tous les flux entrants |
| Commandes perdues si AS400 down | File Redis + retry + alerte |
| Accès non autorisé données clients | RGPD — transmettre le minimum nécessaire |
| Désynchronisation stock | Réconciliation batch quotidienne + alertes divergence |
