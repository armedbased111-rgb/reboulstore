## Annexe — Setup SFTP (VPS, déjà fait)

Session : [[Sessions/archive/2026-05-17-as400-phase1-setup]]

```bash
sudo groupadd sftp-as400
sudo mkdir -p /var/sftp/as400/{entrant,sortant}
sudo useradd -g sftp-as400 -d /var/sftp/as400 -s /usr/sbin/nologin -M sftp-as400
sudo chown root:root /var/sftp/as400 && sudo chmod 755 /var/sftp/as400
sudo chown sftp-as400:sftp-as400 /var/sftp/as400/entrant /var/sftp/as400/sortant
```

Fichier `/etc/ssh/sshd_config.d/sftp-as400.conf` :

```
Match User sftp-as400
    ChrootDirectory /var/sftp/as400
    ForceCommand internal-sftp
    AllowTcpForwarding no
    X11Forwarding no
    PasswordAuthentication yes
    KbdInteractiveAuthentication yes
    AuthenticationMethods password
```

```bash
sudo sshd -t && sudo systemctl reload ssh
sudo passwd sftp-as400
```

## Annexe — Spec CSV (référence)

### Pourquoi pas `orders` ?

L’AS400 intègre des **fichiers de données** en batch, pas une commande web à ressaisir.

### Colonnes (hypothèse = feuille de stock)

| Feuille / AS400 | Reboul BDD |
|-----------------|------------|
| Marque | `brand` |
| Genre | `category` |
| Référence | `reference` (+ size/sku dérivés) |
| Cod Article | `variants.cod_article` |
| Stock | `variant.stock` |

Import Admin : `cod_article;name;reference;brand;category;collection;stock;price` (+ `color;size;sku`). `cod_article` en 1ʳᵉ colonne (vide si inconnu).  
Code : `admin-central/.../reboul-import.service.ts` · ex. `docs/imports/import-stone-island-ss26.csv`

### Delta (sortant) ✅ B3

- Snapshot : `.as400-export-state.json` dans `sortant/` (clé = `sku`).
- **Complet** (1er export, `?full=true`, ou ≥ 7 jours) : header B2 sans `change_type`.
- **Complet** : `cod_article;reference;name;price;sku;size;color;stock`
- **Delta** : `change_type;cod_article;reference;name;price;sku;size;color;stock` — `delete` = ligne retirée du catalogue publié, `stock=0`.
