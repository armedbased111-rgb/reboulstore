## Décision architecture (réunion 12/05)

**Protocole retenu : SFTP bidirectionnel**
- L'AS400 se connecte à notre VPS en SFTP
- Échanges par fichiers (batch horaire dans les deux sens)
- Tout l'implémentation est à notre charge

## Flux retenus

| Flux | Direction | Fréquence | Description |
|------|-----------|-----------|-------------|
| Stocks | AS400 → VPS | Toutes les heures | AS400 dépose un fichier avec tous les stocks Reboul |
| Mouvements | VPS → AS400 | Toutes les heures | On dépose un fichier avec tous nos mouvements (commandes, ventes) |

## Risques

| Risque | Mitigation |
|--------|-----------|
| Fichier stocks malformé → crash parser | Validation + rollback + alerte |
| AS400 ne dépose plus de fichier | Alerte après 2h sans fichier |
| Accès non autorisé au SFTP | Chroot jail + IP whitelist + fail2ban |
| Désync stock | Réconciliation hebdo + alerte divergence > seuil |
