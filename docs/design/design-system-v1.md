# Design System – Reboul v1

## Couleurs
- Fond principal : #FFFFFF
- Texte principal : #0A0A0A
- Texte secondaire : #737373
- Accent sombre (CTA, bordures fortes) : #0A0A0A
- Fonds neutres : #F5F5F5 / #FAFAFA

## Typo / Vibe
- Police : sans serif moderne (équivalent Neue Montreal / Inter)
- Titres : tracking léger, poids moyen, tailles sobres (pas de gros H1 criards)
- Labels : uppercase + tracking large (boutons, sections, badges)

## Layout
- Max width : ~1200–1280px
- Grilles : 2–4 colonnes pour produits
- Espacement vertical généreux (section-padding 48–64px desktop)

## Composants clés
- Bouton primaire : fond noir, texte blanc, uppercase, tracking large
- Card produit : ratio 3/4, hover scale 1.05, texte compact dessous
- Accordéons : séparateurs fins, +/− minimal
